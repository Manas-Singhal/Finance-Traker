# Finance-Traker
This is my SQL project using XAMPP in which, I developed a comprehensive finance tracking system designed to help individuals manage and monitor their personal finances. This project allows users to track income, expenses, and savings, providing detailed insights into their financial habits over time.

The core of the project revolves around SQL databases for data storage and retrieval, ensuring efficient and organized management of financial records. Users can input daily transactions, categorize them into various expense and income types, and view their financial summary through reports and visual charts.

Key features of the project include:

Income and Expense Management: Users can add, edit, and delete records of income and expenses, categorized by type (e.g., salary, bills, groceries).
Monthly and Yearly Reports: The system generates reports for users to analyze their financial patterns, helping them make informed budgeting decisions.
Search and Filter: Users can search for specific transactions and filter results based on timeframes or categories.
Data Security: The project ensures secure data handling with user authentication and backups.
User-friendly Interface: Built using PHP and HTML/CSS, the interface is designed for easy navigation and clear visual representation of financial data.
This project showcases my skills in SQL database management, PHP, and web development, offering a practical solution for personal finance management. It can be easily deployed on any XAMPP server, making it accessible for users to track their finances effectively.
